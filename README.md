# LandInvest — hosted demo bundle

Read-only Streamlit deployment of the LandInvest county dashboard (Guided and Pro experiences). Regenerated from the main repository's `deploy/streamlit_app/` by `scripts/build_streamlit_deploy_bundle.sh`; see `README_DEPLOY.md` for what is included and the data boundary (paid short-term-rental figures are stripped from this public bundle).

Run locally: `pip install -r requirements.txt && streamlit run dashboard.py`. County-level screening only; not investment advice.
